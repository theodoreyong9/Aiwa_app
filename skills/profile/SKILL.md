# Profil

La page de la personne est le dossier `Profile/` de son dépôt de profil : `Profile/index.html` (une page autonome, dessinée comme elle le veut), et `Profile/profile.json` (nom, description courte, liens).

- Garde la page rapide et sobre ; elle s'ouvre comme accueil du téléphone et se met à jour dès un nouveau commit.
- Les boutons d'Aiwa se placent là où la personne le demande (voir `ARCHITECTURE.md`, section accueil).
- Pousse sur la branche indiquée dans les consignes.
