# Vidéos

Promo, tutoriel, animation, film.

- Format : `.mp4` (H.264 + AAC), 1080p maximum, assez léger pour un téléphone.
- Chaîne de fabrication : scénario court → plans (images, texte animé, captures) → assemblage `ffmpeg` → voix off si demandée.
- Un rendu long : programme un contrôle régulier (voir la consigne « Travail long ») ; ce qui est déjà rendu est gardé.
- Regarde des images extraites de la vidéo et vérifie la durée et le son avant de publier.
- Publie selon `skills/release/SKILL.md` avec le tag `video-…`.
